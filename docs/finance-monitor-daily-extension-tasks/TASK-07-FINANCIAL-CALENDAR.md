# TASK-07 — Financial Calendar & Upcoming Cash Flow

## Objective
Help users see what will happen to their money before it happens.

## Requirements
- Month and agenda views.
- Display expected income, bills, subscriptions, loan payments, recurring transfers and financial goals.
- Show next 7/30 day upcoming items.
- Calculate expected inflow/outflow for a selected period.
- Provide a projected balance timeline using current balance plus known scheduled events.
- Allow opening the underlying recurring rule or transaction.
- Visually distinguish expected versus completed events.
- Add reminders for important upcoming obligations.

## Projection Rules
Projection must be deterministic and explicitly based only on known scheduled events. Never imply uncertain future transactions are guaranteed.
