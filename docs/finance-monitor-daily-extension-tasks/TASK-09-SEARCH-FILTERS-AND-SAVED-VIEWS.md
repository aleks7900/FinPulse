# TASK-09 — Powerful Search, Filters & Saved Views

## Objective
Make years of financial history easy to navigate.

## Requirements
- Full transaction search by merchant, description, note and tag.
- Filters for account, category, transaction type, date range, amount range, currency and status.
- Combine filters.
- Sort by newest, oldest, highest and lowest amount.
- Save frequently used filter combinations.
- Provide useful presets: This Month, Last Month, Uncategorized, Subscriptions, Large Expenses and Transfers.
- Maintain responsive performance with tens of thousands of transactions.
- Add appropriate Room indexes and query tests.
