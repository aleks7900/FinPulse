# TASK-05 — Daily Transaction Review Inbox

## Objective
Give users one place to clean up financial data quickly.

## Requirements
Create a Review Inbox containing:
- uncategorized transactions
- imported transactions needing confirmation
- suspected duplicates
- transactions with missing merchant information
- unusual amounts flagged by deterministic rules
- overdue expected bills
- failed recurring transaction generation

## Actions
Support:
- confirm
- categorize
- change account
- edit merchant
- merge/resolve duplicate
- mark recurring bill paid
- dismiss warning
- bulk categorize where safe

## UX
Show the number of items needing attention on the dashboard. The inbox should prioritize actionable items and avoid becoming a noisy notification feed.
